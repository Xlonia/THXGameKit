# 包格式规范 v0（作者 20261111 设计落地）

| 格式 | 内容 | 签名 | 用途 |
|---|---|---|---|
| **.thxp 工程** | 事件五表+事件描述/时间轴 .gd+材质+**角色表+杂兵表** | 无（作者工作文件，可编辑） | 编辑器保存/打开 |
| **.thx 拓展包** | 事件五表+描述/时间轴 .gd+材质 | SHA-256 清单（可选，有则强校验） | mod/剧情/额外弹幕——对 .thxe 做**附加** |
| **.thxe 发布包** | 同 .thxp + 内嵌签名清单 | SHA-256 清单**必须**，装载强校验 | 游戏打包发布（类似 datapacks）——**不可修改** |

## 完整性签名运算

- 保存：①内存组装全部载荷 ②逐文件 SHA-256 → `manifest.txt`
  （每行 `hex␣␣文件名`，尾行 `## package: 总哈希`）③清单+载荷写入 zip
- 装载：.thxe 必须有有效清单且逐文件复算比对——不符即拒载（防恶意代码注入）；
  .thx 有清单则校验，无清单=旧包兼容装载（告警）；目录条目不参与校验
- 【v1 限制】当前=完整性哈希（防意外损坏/朴素篡改）；真·签名（公私钥、
  作者身份认证）属后续版本
## 存放位置（作者 20261111）

- .thxp 默认存 `user://thx_gamekit/`（appdata；对话框默认定位），
  也可存入特定游戏的 gameAssets
- .thxe 由内核从 .thxp 导出、**内嵌在游戏内**随游戏发布，运行时自动读取
- .thx 为对 .thxe 做附加的拓展包
