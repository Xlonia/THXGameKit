# THX 消歧义词典（TERMINOLOGY）

> 目的：把历轮协作中**实际造成过返工/幻觉**的歧义词固定下来。每条给出
> 歧义史（哪轮踩过、后果）与**现行定名**。以后报问题/写修复报告按本词典
> 的定名与模板走。活文档：新歧义出现就追加一条。
>
> 维护：AI（每轮回顾时检查是否有新词需立条）；裁定：作者。

## 一、高频歧义源排行（按历史事故损失排序）

### 1.【工程+界面】二元组缺失 ★最高频★
**歧义史**：同说"贴图有问题"，可能是 自定义对战（battle_arena）／弹幕编辑器
通用参数页／试炼场／弹幕显示浮窗 四处之一。20261112 轮：20:00 已修自定义
对战侧，作者所指为编辑器预览侧——修理方向错位一轮。
**定名**：报显示类问题必须带【工程 + 界面位置 + 现象 + 期望】四元组。
界面位置用本词典第二节的固定界面名。

### 2.「预览」四义
| 固定名 | 指 | 位置 |
|---|---|---|
| **材质预览卡** | 通用参数页底部"材质/判定盒/旋转中心"专属行列段落（PreviewOverlay） | 编辑器·弹幕页·通用参数 |
| **弹幕显示浮窗** | 独立 OS 窗口迷你舞台（Z 发射/Esc 关） | 编辑器底栏按钮 |
| **试炼场** | 替换主窗口的弹幕沙盒（▶试炼场预览按钮） | 编辑器底栏按钮 |
| **编辑器内嵌** | THX75 内以替换主窗方式打开的编辑器本体 | THX75 菜单 |
**歧义史**：三种"预览"混说导致修错窗口；"浮窗错位遮字幕"实为材质预览卡
叠在表单 grid 上（20261112 修）。

### 3.「根 / 根目录」指到哪一层
**歧义史**：DATA_BASE=材质根目录**本身**（…/danmaku16pxs/）还是其父目录
（…/shooting/）——内核与宿主各按一种理解实现，二次 join 后目录不存在
→ 全弹白圆（0.0.9 内核化轮）。
**定名**：凡说"根"，必须给出**完整示例路径**（到文件名一层）。现行协议：
`DATA_BASE = …/danmaku16pxs`（目录本身）；角色贴图 `chars_dir() =
…/textures/chars`（目录本身）。

### 4.「字幕」三义
- **HUD 字幕**：战场消息条（结算/指令失败提示）。
- **状态栏**：编辑器底栏左侧的编译错误/操作反馈文字。
- **字段标签**：表单每行左侧的参数名文字（如"伤害(整式)"）。
**歧义史**：20261112"预览遮蔽字幕"=字段标签（材质预览卡叠表单）。
**定名**：三者不得统称"字幕"；报障时用上表固定名。

### 5.「占位」三义
- **占位场景**：剧情/EX 的 placeholder 场景（待实装）。
- **占位列**：CSV 已建列但暂不生效（如 clash_ddm_s）。
- **布局占位**：为将来内容预留的空行列/空槽（如标题画面背景槽）。
**定名**：说"占位"时注明属于哪一类。

### 6. N/I/S 的三层归属（20261112 裁定落地）
| 层 | 归属 | 现状 |
|---|---|---|
| **数据列** dmg_mode | CSV 格式层 | 内核保留解析/写回（往返无损），编辑器**不提供选取入口** |
| **选取入口** | 编辑器 UI | 裸本体不可选取（20261112 清除）；宿主侧按需自建控件 |
| **结算逻辑** | 玩法层 | 自走棋插件 BattleEntity.take_hit 覆盖；内核=虚方法桩 |
**定名**："内核不要 N/I/S" 默认指**结算+选取入口**两层；数据列属文件格式，
与玩法解耦。

### 7.「判定盒」三义
- **判定半径**：Determine 列（数值，自机被弹判定圆）。
- **特殊判定盒**：hitbox 黑白位图（THX 系列默认关，编辑器设置菜单开关）。
- **物理碰撞**：物弹/杂兵碰撞（is_phy 口径）。
**定名**：位图义必须写全"特殊判定盒（位图）"。

### 8. 工程指代
- **THX75**＝游戏本体（github.com/Xlonia/THX75）；内部旧名"消望"。
- **THXGameKit**＝内核 addon 仓库；th75 以 submodule 挂载于
  `addons/thxgamekit/kit/`。
- **裸本体**＝THXGameKit 独立打开（无 th75 宿主）。
**定名**：修复报告必须写明**仓库 + 文件**；"上轮修的地方错了"类反馈
请指出当时所指的界面（见第 1 条）。

### 9. 版本口径
- **m 编号**＝commit 轮次，只增不减（m10 起）。当前见仓库最新 commit。
- **v0.0.x**＝游戏版本（当前 v0.0.9）。
**定名**："版本"单说=v0.0.x；说单轮工作用 m 编号。

### 10. 路径口径（挂载点无关）
- 内核内部代码写 `res://addons/thx_gamekit/...`（**逻辑路径**），运行经
  `THXKit.kpath()` 重写到实际挂载点（GameKit 独立=同路径；th75=
  `res://addons/thxgamekit/kit/addons/thx_gamekit/...`）。
**定名**：对话中给作者看的路径一律用**实际挂载路径**；代码/文档引用
逻辑路径并注明。

### 11. 数量/布局词
- **专属行列**＝表单下方整段预留区（20261112 材质预览卡落位）。
- "行列"在不指明时默认指**编辑器表单区**，不是 CSV 行列、不是弹幕网格。

## 二、固定界面名速查（报障用）
| 固定名 | 所属 | 入口 |
|---|---|---|
| 标题画面 | THXGameKit 独立工程主场景 | 启动即见（编辑器/帮助文档/选项/测试/关于我们/退出） |
| 弹幕页·通用参数 | 编辑器 | 左侧"弹幕"页签·Tab1 |
| 材质预览卡 | 同上·表单下方专属行列 | 判定盒显示/旋转中心显示 两开关 |
| 弹幕页·弹幕表达 | 编辑器 | Tab2（按行进类型互斥） |
| 角色页·角色贴图 | 编辑器 | 角色页签·贴图节（导入/清除/预览） |
| 试炼场 | 替换主窗 | 底栏"▶ 试炼场预览"；右侧常驻"✕ 退出试炼场" |
| 弹幕显示浮窗 | OS 窗口 | 底栏"弹幕显示浮窗(Z发射)" |
| 选项·内容文件夹 | 标题画面 | 弹幕材质/判定盒图/角色贴图/音乐音效 四行 |
