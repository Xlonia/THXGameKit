# THX 消歧义词典（TERMINOLOGY）

> 目的：把历轮协作中**实际造成过返工/幻觉**的歧义词固定下来。每条给出
> 歧义史（哪轮踩过、后果）与**现行定名**。活文档：新歧义出现就追加。
>
> **2026-11-12 作者全面定名**（第二节逐条裁定），双方此后使用同义。
>
> 维护：AI（每轮回顾时检查新词需立条）；裁定：作者。

## 一、作者定名（20261112，含裁定理由）

### 1. 贴图 = 材质
**定名**：**贴图**=附着在一个实例或实体上的具象化（弹幕、角色等）的**材质**。
两词同指；涉及"挂在实体上"的语境优先用"贴图"，涉及库/文件/选取语境用"材质"。

### 2. "预览"四分名（原四义各自定名）
| 旧混称 | **定名** | 指 | 位置 |
|---|---|---|---|
| 材质预览（卡） | **展示** | 通用参数页下方专属行列段（材质+判定盒+旋转中心） | 编辑器·弹幕页 |
| 弹幕显示浮窗 | **弹幕预览** | 独立窗口迷你舞台（Z 发射/Esc 关） | 编辑器底栏"弹幕预览(Z发射)" |
| 试炼场 | **试炼场** | 替换主窗口的弹幕沙盒（含"试炼场"字样，无歧义） | 编辑器底栏"▶ 试炼场" |
| 编辑器内嵌 | **预览窗** | THX75 内以替换主窗方式打开的编辑器本体 | THX75 菜单 |

### 3. 根目录 / 上级目录
**定名**：**根目录**=最顶部的工程根（`game` 或 `th75`/`THXGameKit`）；
中间层的上级只称**上级目录**，不得叫"根"。
（史：DATA_BASE"根本身 vs 父目录"二义→全弹白圆。现表述材质目录时写完整路径。）

### 4. HUD / 字幕
**定名**：战场 HUD 上的显示称 **HUD**；其余 UI 上显示的文字（编辑器状态栏、
字段名、面板提示等）统称**字幕**（报障时加位置限定，如"弹幕页字幕"）；
不得用"字幕"概括 HUD 内容。

### 5. N/I/S 全层=插件泛化
**定名**：**数据列、选取入口、结算三层全部属插件泛化**——能用作该玩法
的也就是 THX75 类游戏。内核不为其提供原生支持承诺：dmg_mode 列在内核
CSV_HEADER 中保留仅为 THX75 数据往返兼容（内核编辑器无选取入口、无结算）。

## 二、高频歧义源（历史事故排行，含裁定前条目）

### 6.【工程+界面】二元组缺失 ★最高频★
**歧义史**：同说"贴图有问题"，可能是 自定义对战／编辑器展示／试炼场／
弹幕预览 四处之一。20261112 轮：20:00 已修自定义对战侧，作者所指为编辑器
展示侧——方向错位一轮。
**定名**：报显示类问题必须带【工程 + 界面位置 + 现象 + 期望】四元组。
界面位置用本文件固定名。

### 7. "占位"三义
- **占位场景**：剧情/EX 的 placeholder 场景（待实装）。
- **占位列**：CSV 已建列但暂不生效（如 clash_ddm_s）。
- **布局占位**：为将来内容预留的空行列/空槽（如标题画面背景槽）。
**定名**：说"占位"时注明属于哪一类。

### 8. "判定盒"三义
- **判定半径**：Determine 列（数值，自机被弹判定圆）。
- **特殊判定盒**：hitbox 黑白位图（白像素=有判定；THX 系列默认关，
  编辑器设置菜单开关；**"同显示"=判定形状直接用弹幕材质**——作者 20261112，
  省做单独判定盒图）。
- **物理碰撞**：物弹/杂兵碰撞（is_phy 口径）。
**定名**：位图义必须写全"特殊判定盒（位图）"。

### 9. 工程指代
- **THX75**＝游戏本体（github.com/Xlonia/THX75）；内部旧名"消望"。
- **THXGameKit**＝内核 addon 仓库；th75 以 submodule 挂载于
  `addons/thxgamekit/kit/`。
- **裸本体**＝THXGameKit 独立打开（无 th75 宿主）。
**定名**：修复报告必须写明**仓库 + 文件**。

### 10. 版本口径
- **m 编号**＝commit 轮次，只增不减。当前见仓库最新 commit。
- **v0.0.x**＝游戏版本（当前 v0.0.9）。
**定名**："版本"单说=v0.0.x；说单轮工作用 m 编号。

### 11. 路径口径（挂载点无关）
- 内核内部代码写 `res://addons/thx_gamekit/...`（**逻辑路径**），运行经
  `THXKit.kpath()` 重写到实际挂载点（裸本体=同路径；th75=
  `res://addons/thxgamekit/kit/addons/thx_gamekit/...`）。
**定名**：对话中给作者看的路径一律用**实际挂载路径**；代码/文档引用
逻辑路径并注明。

## 三、固定界面名速查（报障用）
| 固定名 | 所属 | 入口 |
|---|---|---|
| 标题画面 | THXGameKit 独立工程主场景 | 启动即见（编辑器/帮助文档/选项/测试/关于我们/退出） |
| 弹幕页·通用参数 | 编辑器 | 顶栏"编辑器"页签→左侧"弹幕"→Tab1 |
| 展示（卡） | 同上·表单下方专属行列 | 判定盒显示/旋转中心显示 两开关；红=判定区白像素 |
| 弹幕页·弹幕表达 | 编辑器 | Tab2（按行进类型互斥） |
| 角色页·角色贴图 | 编辑器 | 角色页签·贴图节 |
| 设置页 | 编辑器顶栏 | "设置"页签（当前工程/保存/draft/内容文件夹/重扫） |
| 探针页 | 编辑器顶栏 | "探针"页签（事件统计/材质缺失/编译状态） |
| 试炼场 | 替换主窗 | 底栏"▶ 试炼场"；右侧常驻"✕ 退出试炼场" |
| 弹幕预览 | OS 窗口 | 底栏"弹幕预览(Z发射)" |
| 选项·内容文件夹 | 标题画面 | 弹幕材质/判定盒图/角色贴图/音乐音效 四行 |
| 退出确认面板 | 编辑器树内自绘 | 文件菜单退出类项（保存并退出→.thxp） |
